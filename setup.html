passo 1 de 5

Criar projeto no Google Cloud

Precisamos de um projeto no Google Cloud para habilitar o login com Google e o acesso às planilhas. Leva menos de 2 minutos!

  1. 1 Abra o Google Cloud Console numa nova aba
  2. 2 Em Project name, escreva wonuskiz-mail
  3. 3 Clique em Create e aguarde o projeto ser criado
  4. 4 Certifique que o projeto wonuskiz-mail está selecionado no topo da página
Você precisa estar logada com a mesma conta Google que vai usar no wonuskiz-mail

passo 2 de 5

Ativar as APIs necessárias

Precisamos ativar a Google Sheets API para o site conseguir ler e escrever na planilha.

  1. 1 Clique aqui para abrir diretamente: Google Sheets API
  2. 2 Clique no botão azul Ativar (ou Enable)
  3. 3 Aguarde a ativação e volte aqui
Só precisamos da Sheets API — nada mais!

passo 3 de 5

Criar o Client ID do OAuth

Esse é o passo mais importante — ele cria a "chave" que permite o login com Google no seu site.

  1. 1 Abra Credenciais no Google Cloud
  2. 2 Clique em + Criar credenciais → ID do cliente OAuth 2.0
  3. 3 Se pedir pra configurar a tela de consentimento, escolha Externo, preencha só o nome do app (wonuskiz-mail) e seu e-mail, e salve
  4. 4 De volta em Credenciais, clique em + Criar credenciais → ID do cliente OAuth 2.0
  5. 5 Tipo: Aplicativo da Web
  6. 6 Em Origens JavaScript autorizadas, adicione:
https://ludyta.github.io
  1. 7 Clique em Criar e copie o ID do cliente que aparece

passo 4 de 5

Ativar o GitHub Pages

O GitHub Pages vai publicar seu site e deixá-lo acessível na internet — de graça!

  1. 1 Abra Settings → Pages do repositório
  2. 2 Em Source, selecione Deploy from a branch
  3. 3 Em Branch, selecione main e / (root)
  4. 4 Clique em Save
  5. 5 Aguarde cerca de 1-2 minutos e clique em Verificar abaixo
