Criar projeto no Google Cloud

Precisamos de um projeto no Google Cloud para habilitar o login com Google e o acesso às planilhas. Leva menos de 2 minutos!

  1. 1 Abra o Google Cloud Console em outra aba
  2. 2 Em Project name, escreva wonuskiz-mail
  3. 3 Clique em Create e aguarde o projeto ser criado
  4. 4 Certifique que wonuskiz-mail está selecionado no topo da página
Use a mesma conta Google que vai usar no wonuskiz-mail

passo 2 de 4

Ativar API e criar Client ID

Vamos ativar a Sheets API e criar a chave de login OAuth em um só passo.

  1. 1 Ative a Google Sheets API — clique em Ativar
  2. 2 Abra Credenciais e clique em + Criar credenciais → ID do cliente OAuth 2.0
  3. 3 Se pedir a tela de consentimento: escolha Externo, preencha só o nome do app e seu e-mail, salve
  4. 4 Tipo de aplicativo: Aplicativo da Web
  5. 5 Em Origens JavaScript autorizadas, adicione exatamente:
https://courageous-cupcake-a111ec.netlify.app
  1. 6 Clique em Criar e copie o ID do cliente que aparece

passo 3 de 4

Colar o Client ID

Cole o Client ID que você copiou agora. Ele será salvo no seu navegador para o site funcionar.

O Client ID é salvo só no seu navegador — ninguém mais tem acesso
